# 시군구별 어린이 1만 명당 소아청소년과 전문의 수

전국 230개 시군구의 0~14세 어린이 1만 명당 소아청소년과 전문의 수를 계산한 데이터 기사 페이지(`index.html`)의 출처, 계산법, 한계를 정리한 문서입니다.

## 핵심 수치 (코드로 계산)

| 항목 | 값 |
|---|---|
| 시군구 수 | 230곳 |
| 소아청소년과 전문의 합계 | 5,890명 |
| 전문의가 1명 이상인 기관 수 | 3,183곳 |
| 0~14세 인구 합계 (2026년 9월) | 5,116,175명 |
| 전국 어린이 1만 명당 전문의 | 11.51명 |
| 전문의 0명 시군구 | 23곳 |
| 최고 | 서울특별시 종로구 121.28명 |
| 최저(0명 제외) | 충청북도 증평군 2.62명 |

## 출처와 기준일

1. **소아청소년과 전문의 수**: 건강보험심사평가원 「전국 병의원 및 약국 현황」 (공공데이터포털), 2026년 9월 30일 기준
   - `1.병원정보서비스(2026.9.).csv`: 요양기관 주소
   - `5.의료기관별상세정보서비스_03_진료과목정보(2026.9.).csv`: 진료과목별 전문의 수
2. **어린이 수**: 행정안전부 주민등록인구통계, KOSIS 표 `DT_1B04005N` 「행정구역(읍면동)별/5세별 주민등록인구」, 2026년 9월 값

## 계산 방법

1. 진료과목정보에서 진료과목코드 `11`(소아청소년과) 행의 '과목별 전문의수'를 기관(암호화요양기호)별로 더했습니다.
2. 병원정보와 '암호화요양기호'로 연결해 기관 주소를 붙였습니다. 연결되지 않은 기관은 없었습니다.
3. 시군구는 주소의 앞 두 단어입니다. 세종특별자치시는 하나의 시군구로 보고, '광주광역시'와 '전라남도'로 시작하는 옛 주소는 '전남광주통합특별시'로 바꿨습니다.
4. KOSIS 표에서 총인구수 중 0~4세, 5~9세, 10~14세의 2026년 9월 값을 더했습니다. 시도 이름 행 아래 행을 그 시도의 시군구로 보고, 전국 행, 시도 합계 행, 출장소 행(경기 북부출장소, 강원 동해출장소)은 뺐습니다. 세종은 한 번만 셌습니다.
5. 지표 = 전문의 수 ÷ 0~14세 인구 × 10,000
6. 순위는 반올림하기 전 값으로 매겼습니다. 값이 같으면 같은 순위(공동)를 줍니다. 전문의 0명인 23곳은 공동 208위입니다.

### 검산
- 시군구별 0~14세 인구를 더하면 KOSIS '전국' 행 값(5,116,175명)과 같습니다.
- 시군구별 전문의 수를 더하면 진료과목 파일의 코드 11 전체 합계(5,890명)와 같습니다.
- 심평원 쪽 시군구 이름은 모두 KOSIS 시군구와 연결됐습니다(불일치 0곳).

## 한계

- **신고 기준 인원입니다.** '과목별 전문의수'는 기관이 심평원에 신고한 인원이라 실제 외래 진료 의사 수와 다를 수 있습니다. 대학병원 같은 큰 병원의 입원·교수 인력도 포함됩니다.
- **병원 주소 기준입니다.** 어린이는 다른 시군구 병원도 다니므로, 이 수치가 실제 생활권 접근성과 같지 않습니다. 큰 병원이 있는 시군구는 수치가 높게 나옵니다.
- **소아청소년과 전문의만 셉니다.** 가정의학과 등 다른 과 의사나 일반의가 어린이를 진료하는 경우는 빠집니다. 따라서 전문의 0명이 곧 어린이 진료 기관이 없다는 뜻은 아닙니다.
- **0~14세만 셉니다.** 소아청소년과는 18세 미만까지 진료하지만, 15~17세는 분모에 넣지 않았습니다.
- **어린이가 적은 곳은 수치가 크게 흔들립니다.** 전문의 1명 차이로 값과 순위가 크게 바뀔 수 있습니다.
- **주민등록 기준입니다.** 실제 거주 인구와 다를 수 있습니다.
- **행정구역 기준:** 일반구가 있는 시(예: 수원시)는 시 단위로 합쳤습니다. 인천은 2026년 개편된 구(제물포구·영종구·서해구·검단구 등) 기준입니다.
